## Versionamento Semântico
É um conjunto de regras que ajuda a padronizar e manter um controle e visibilidade melhor sobre o versionamento e andamento de um projeto.

## MAJOR.MINOR.PATCH

MAJOR seria a versão principal, assim, indicando mudanças incompatíveis,onde ocorre mudanças drásticas na estrutura da API ou outros recursos.  
Ex: 1.9.3 -> 2.0.0

MINOR é uma versão secundária, indicando a adição de novas funcionalidades porém mantendo a compatibilidade com as versões anteriores.
Ex: 2.1.4 -> 2.2.0

PATCH seria a correção de bugs, onde são corrigidos erros ou pequenas otimizações de desempenho e que também não interferem na compatibilidade.
Ex:2.2.0 -> 2.2.1
